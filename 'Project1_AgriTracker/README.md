# Greenfield Agriculture – Crop Performance & Analytics Dashboard

## Project Overview
An Excel-based data analytics project designed to analyze agricultural crop performance, yield, input costs, rainfall, soil conditions, irrigation, and seasonal trends.

## Objectives
- Analyze crop yield across districts and seasons.
- Compare crop performance under different soil and irrigation conditions.
- Explore rainfall patterns and their relationship with crop productivity.
- Present key agricultural metrics through an Excel dashboard.

## Tools Used
- Microsoft Excel
- Excel formulas and data cleaning
- Pivot tables and charts
- Data analysis and dashboard visualization

## Workbook Structure
- `RAW DATA` – Original dataset.
- `Clean_Data` – Prepared dataset.
- `Analysis` – Analytical calculations and comparisons.
- `Pivot_Backend` – Supporting pivot tables.
- `Dashboard` – Visual summary of agricultural performance.

## Key Areas of Analysis
- District-wise crop yield
- Seasonal crop performance
- Soil productivity
- Rainfall and irrigation analysis
- Year-wise trends and input costs

## How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Explore the analysis and dashboard sheets.

## Project Type
Portfolio project for Excel data analytics and business intelligence practice.
